# Hosted cross-mode calibration evidence

The stored application-path fixtures cover commercial, documentary, narrative, performance, and
open/ambiguous projects. Each fixture records the real hosted provider identifier, input brief,
provider output, application quality gate, current persisted Blueprint, creative-quality report, and
visual-quality report. `cross-mode-hosted-artifacts.test.ts` revalidates those artifacts against the
current domain schema and verifies that mode differences change story engine, scene action, camera,
sound, and separately composed 16:9/9:16 planning—not merely labels.

The Jimmy fixture also retains a raw general-purpose baseline. Automated comparison may identify
concrete differences such as crop-derived vertical planning, generic craft defaults, application
schema conformance, and Stroman's project-specific quality scores. It must not claim that an
automatic score replaces a blind filmmaker judgment; the raw output and Stroman artifact remain
available for independent review.

These files are durable evidence from the real hosted Responses API path. They can be re-generated
with `npm run calibrate:hosted` and `npm run calibrate:baseline` only when an owner-hosted reasoning
credential and usage authorization are available. Offline/deterministic operation remains a test and
recovery path and intentionally fails closed instead of claiming hosted editorial quality.
